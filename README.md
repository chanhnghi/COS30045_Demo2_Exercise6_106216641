# Exercise 6 — Interactivity

Open `index.html` through a local web server such as VS Code Live Server so D3 can load the CSV file. The page combines an interactive TV energy histogram and a scatterplot of star rating versus energy use.

The technology filter and minimum star-rating slider update both charts. In **All TVs**, each energy bin is stacked by LCD, LED, and OLED; choosing one technology shows only that category. Hover a histogram segment to see its count or a scatterplot point to see the TV details.
